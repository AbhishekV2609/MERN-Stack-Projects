# REST API CRUD App (EJS)

A RESTful CRUD application built using Node.js, Express, and EJS.

## Features
- Create Post
- View All Posts
- View Single Post
- Edit Post
- Delete Post
- Unique ID using UUID
- Method Override for PATCH & DELETE

## Tech Stack
- Node.js
- Express.js
- EJS
- UUID
- Method-Override

## Installation

```bash
git clone https://github.com/AbhishekV2609/Rest-API-Crud-EJS.git
cd Rest-API-Crud-EJS
npm install
node index.js
