# 🛒 E-Commerce Project

A modern and responsive E-Commerce web application built using React.js and Redux Toolkit. This project includes authentication, user profile management, cart functionality, wishlist, orders, and a clean UI for a complete shopping experience.

---

## 🚀 Features

* 🔐 User Login & Signup
* 👤 Dynamic User Profile
* 🛍️ Add to Cart
* ❤️ Wishlist Management
* 📦 Orders Section
* 🏠 Address Management
* 💳 Payment Methods
* 📱 Fully Responsive UI
* ⚡ Redux Toolkit State Management

---

## 🛠️ Tech Stack

* React.js
* Redux Toolkit
* React Router DOM
* CSS Modules
* JavaScript
* SweetAlert2

---

## 📂 Project Setup

### Clone the Repository

```bash
git clone https://github.com/AbhishekV2609/E-commerce_project.git
```

### Move into Project Folder

```bash
cd E-commerce_project
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm start
```
